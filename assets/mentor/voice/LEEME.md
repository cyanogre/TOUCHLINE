# Doblaje del Profe

Coloca aquí los audios (MP3) con estos nombres exactos. El juego los usa solos;
si falta alguno, en su lugar suenan los pitidos de siempre.

Voz: **Rafael – Tales and Legends** (ElevenLabs, español de España). Modelo: Eleven v4.

| Archivo | Texto a generar |
|---|---|
| `hola.mp3` | [warmly] ¡Hombre, míster! |
| `escucha.mp3` | Escucha, míster. |
| `aver.mp3` | [thoughtfully] A ver, a ver... |
| `bien.mp3` | [happily] ¡Así se hace! |
| `orgullo.mp3` | [proudly] ¡Eso es, chaval! |
| `ay.mp3` | [sighs] Ay, ay, ay... |
| `tranquilo.mp3` | [calmly] Tranquilo, míster. |
| `secreto.mp3` | Te voy a contar una cosa... |
| `campeones.mp3` | [laughs] ¡Campeones! |
| `mira.mp3` | Mira... |
| `pena.mp3` | [sadly] Qué le vamos a hacer... |

Cuándo suenan: `hola` al empezar el tutorial, `secreto` en las lecciones, y el resto según la
emoción de la primera frase del diálogo (alegría, orgullo, preocupación, tristeza, reflexión…),
como mucho una vez cada 25 segundos para que no canse.
